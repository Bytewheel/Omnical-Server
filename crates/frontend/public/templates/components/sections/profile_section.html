New here? What is Omnical…

Omnical is where your calendars, tasks and contacts are stored; you see and edit them in the calendar and contacts apps you already use — iPhone/iPad/Mac, Android, or Thunderbird. This website is the control panel: account settings, connecting your apps, and sharing.

Your account already contains a personal calendar, a tasks list and a contacts book — they sync to your apps as soon as one is connected. To connect an app: add the name of the app to be used in the App name input below, and click Add. The password generated is for your calendar app — it's different from the one you sign in to this website with. Then follow the steps in How to connect your apps. Share links that let others (or Google Calendar) view a calendar read-only are in the Calendars section below. Contacts can be brought over from other services — like Google or Apple — with the Import contacts button in the Addressbooks section.

How to connect your apps…

Create a password for one app. Any app that can sync calendars (CalDAV) or contacts (CardDAV) is supported. You will need three things: the app's username (below), the password (generate one above — one per app), and the server address (below). Copy each into the app's "add account" screen.

  • Username: {{ user.id }} — your login name, not your email address.
  • Password: the password — generate one with the form above, one per app, e.g. hawkbook or thunderbird.
  • Calendar server address: {{ caldav_url }}
  • Contacts server address: {{ carddav_url }}

The password is only shown once when it's created — this server stores it scrambled, so nobody (not even you) can look it up afterwards. If you lose it: press Regenerate next to the app name above — the app keeps its name and full access, the old password stops working, and the new one is shown once. Disconnecting an app signs that app out everywhere.

Calendars

  • iPhone/iPad/Mac: Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account → server {{ caldav_url }}, user = {{ user.id }}, password.
  • Android: the built-in Google Calendar app cannot add another calendar server — install HawkBook/DavX → add account → CalDAV → paste {{ caldav_url }} + username + password.
  • Thunderbird: Calendar → New Calendar → On the Network → paste {{ caldav_url }} + username + password.
  • Google Calendar & Outlook.com: neither can follow another calendar server — share a read-only subscribe link from the Calendars section instead.

Contacts

  • iPhone/iPad/Mac: Settings → Contacts → Accounts → Add Account → Other → Add CardDAV Account → server {{ carddav_url }}, user = {{ user.id }}, password.
  • Android: install HawkBook/DavX → add account → CardDAV → paste {{ carddav_url }} + username + password (the same HawkBook/DavX account syncs both).
  • Thunderbird: add the CardDAV address book at {{ carddav_url }} with the same username and password.

Moving your existing calendar or contacts in

  • Contacts (from Google, Apple, Outlook, …): export them as a .vcf file (in Google: contacts.google.com → Export → vCard) and use the Import contacts button in the Addressbooks section. Duplicates are skipped automatically.
  • Calendars: the Import calendar button in the Calendars section reads an .ics file (Google: calendar settings → Export).
