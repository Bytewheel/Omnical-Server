New here? What is Omnical…

This website has no calendar on it. Omnical is where your calendars, tasks and contacts are stored; you see and edit them in the calendar and contacts apps you already use — iPhone/iPad/Mac, Android, or Thunderbird. This website is the control panel: account settings, connecting your apps, and sharing.

Your account already contains a personal calendar, a tasks list and a contacts book — they sync to your apps as soon as one is connected. To connect an app, create an app token below (the password your calendar app uses — different from the one you sign in to this website with) and follow How to use app tokens…. Share links that let others (or Google Calendar) view a calendar read-only are in the Calendars section below.

App tokens

App tokens are the passwords your calendar and contacts apps use to sign in to this server — one per app (e.g. hawkbook, thunderbird, apple), each with full read + write access to your calendars, tasks and contacts. The token's value is only shown once, right after you generate it. If you lose one, Regenerate it: the app keeps its name and full access, the old secret stops working, and the new one is shown once. How to use app tokens…

An app token works like a per-app password. Any app that speaks CalDAV (calendars, tasks) or CardDAV (contacts) signs in with:

  • Username: {{ user.id }} — your login name, not your email address.
  • Password: the app token — generate one with the form above, one per app, e.g. hawkbook or thunderbird.
  • Calendar server (CalDAV): {{ caldav_url }}
  • Contacts server (CardDAV): {{ carddav_url }}

The token value is only shown once when it's created — the server stores it hashed, so nobody (not even you) can look it up afterwards. If you lose it: press Regenerate next to the token above — the app keeps its name and full access, the old secret stops working, and the new one is shown once. Deleting a token signs that app out everywhere.

Calendars (CalDAV)

  • Apple iPhone/iPad/Mac: Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account → server {{ caldav_url }}, user = {{ user.id }}, password = the app token.
  • Android: the built-in Google Calendar app cannot add an external CalDAV server — install HawkBook/DavX → add account → CalDAV → paste {{ caldav_url }} + username + app token.
  • Thunderbird: Calendar → New Calendar → On the Network → paste {{ caldav_url }} + username + app token.
  • Google Calendar & Outlook.com: not possible — neither supports adding an external CalDAV server; use a calendar's read-only subscribe link from the Calendars section instead.

Contacts (CardDAV)

  • Apple iPhone/iPad/Mac: Settings → Contacts → Accounts → Add Account → Other → Add CardDAV Account → server {{ carddav_url }}, user = {{ user.id }}, password = the app token.
  • Android: install HawkBook/DavX → add account → CardDAV → paste {{ carddav_url }} + username + app token (the same HawkBook/DavX account syncs both).
  • Thunderbird: add the CardDAV address book at {{ carddav_url }} with the same username and app token.
