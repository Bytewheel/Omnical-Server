App tokens

App tokens are the passwords your calendar and contacts apps use to sign in to this server — one per app (e.g. davx5, thunderbird, apple), each with full read + write access to your calendars, tasks and contacts. The token's value is only shown once, right after you generate it. If you lose one, Regenerate it: the app keeps its name and full access, the old secret stops working, and the new one is shown once. How to use app tokens…

An app token works like a per-app password. Any app that speaks CalDAV (calendars, tasks) or CardDAV (contacts) signs in with:

  • Username: {{ user.id }} — your login name, not your email address.
  • Password: the app token — generate one with the form above, one per app, e.g. davx5 or thunderbird.
  • Calendar server (CalDAV): {{ caldav_url }}
  • Contacts server (CardDAV): {{ carddav_url }}

The token value is only shown once when it's created — the server stores it hashed, so nobody (not even you) can look it up afterwards. If you lose it: press Regenerate next to the token above — the app keeps its name and full access, the old secret stops working, and the new one is shown once. Deleting a token signs that app out everywhere.

Calendars (CalDAV)

  • Apple iPhone/iPad/Mac: Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account → server {{ caldav_url }}, user = {{ user.id }}, password = the app token.
  • Android: the built-in Google Calendar app cannot add an external CalDAV server — install DAVx5 → add account → CalDAV → paste {{ caldav_url }} + username + app token.
  • Thunderbird: Calendar → New Calendar → On the Network → paste {{ caldav_url }} + username + app token.
  • Google Calendar & Outlook.com: not possible — neither supports adding an external CalDAV server; use a calendar's read-only subscribe link from the Calendars tab instead.

Contacts (CardDAV)

  • Apple iPhone/iPad/Mac: Settings → Contacts → Accounts → Add Account → Other → Add CardDAV Account → server {{ carddav_url }}, user = {{ user.id }}, password = the app token.
  • Android: install DAVx5 → add account → CardDAV → paste {{ carddav_url }} + username + app token (the same DAVx5 account syncs both).
  • Thunderbird: add the CardDAV address book at {{ carddav_url }} with the same username and app token.
