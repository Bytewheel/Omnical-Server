Journaling — notes & diaries on this calendar

This calendar supports VJOURNAL entries: dated text notes such as meeting minutes, a work log, or a private diary. A journal entry occupies no time on a calendar and never turns into a meeting invitation, so it won't show up in free/busy or attendee lists.

Android — jtx Board (the app that supports journals)

  1. Install jtx Board, and install DAVx⁵ if you don't have it (jtx Board syncs through it).
  2. In DAVx⁵ → CalDAV tab → tap your account → check this calendar to mark it for sync. This calendar already declares VJOURNAL, so DAVx⁵ will pick it up as a journal-capable collection.
  3. Run a sync, then open jtx Board. This calendar appears under its own section, and you can create Journals (with a date) and Notes (no date) there.
  4. In jtx Board you can also link a note or journal to a task with RELATED-TO — useful for a meeting's minutes next to the follow-up tasks.

Linux desktop — Evolution

  1. Evolution → File → New → Memo List…
  2. Choose CalDAV as the type, then paste the calendar URL: {{ caldav_url }}/{{ calendar.principal }}/{{ calendar.id }}/
  3. Enter your username and the same app token you use for the calendar, then click Find Calendars to let Evolution pick the URL, and click OK.
  4. Evolution stores memos as VJOURNAL, so entries you write in the Memo List appear in your other devices' journal apps and vice versa.

What won't work

  • Apple Calendar (iPhone/iPad/Mac), Google Calendar, Outlook — none of them implement VJOURNAL. They will sync this calendar's events and tasks fine and simply ignore journal entries. Entries written in jtx Board or Evolution stay on the server, they just won't display in these apps.
  • Thunderbird — supports VEVENT and VTODO but not VJOURNAL, so journals won't appear there either.
  • The read-only subscribe link is a plain ICS feed and works in any app that accepts one, but clients that don't understand VJOURNAL still won't show the entries.

Importing and exporting

  • Use Import calendar on the Calendars tab to upload an .ics file containing journal entries — the calendar will pick up VJOURNAL support from the file.
  • The Download button on the Calendars tab exports every entry, journals included, in one .ics file.
  • Unchecking VJOURNAL in the calendar's Edit form stops new journal entries from being written. Entries already stored stay readable and can still be edited.
